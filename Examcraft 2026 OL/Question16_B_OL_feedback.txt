There are two functions max() and min() which will return the max and min values of a list
maximum = max(weekly_steps)
minimum = min(weekly_steps)

To find them from a list if you don't have the max() and min() functions.

First set a maximum and a minumum variable both to the first element in the list

maximum = weekly_steps[0]
minimum = weekly_steps[0]

then run a loop over the list

for i in weekly_steps:
    if i>maximum:
        maximum = i
    if i<minimum:
        minimum = i
