line 7:vowel=("a","e,i,o,u")
- round brackets make a tuple, square brackets make a list [].
- nothing wrong with a tuple but you need to quote each letter separately like you would a list
vowel = ("a","e","i","o","u") otherwise you have two strings "a" and "e,i,o,u"

line 12:     if i==vowel:
- this works for comparing two letters "a" == "b" for example. You want to check if i is
one of the letters in the tuple vowel. So, you need to use the membership operator (in)

if i in vowel
